# La 105 Fast Food - Demo

Sitio de demostración (HTML + CSS + JS, sin instalar nada).

## Verlo en tu computadora
- Doble clic en `index.html`, o
- con servidor local: `python3 -m http.server 8000` y abrir http://localhost:8000

## Publicarlo gratis en GitHub Pages
1. Subí esta carpeta a un repositorio nuevo.
2. Settings > Pages > Branch: main / (root) > Save.
3. En un minuto queda en https://TU-USUARIO.github.io/NOMBRE-REPO/

Nota: cuentas, destacados y puntajes se guardan solo en el navegador (demo).
